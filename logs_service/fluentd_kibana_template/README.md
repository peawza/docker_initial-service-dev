# Fluentd + Kibana Template Stack (Separated)

This stack is isolated from the original `logs_service/fluentd` setup.
It includes:
- Elasticsearch + Kibana with login enabled
- Fluentd forwarding logs to `fluentd-template-*`
- Linux/API log simulators
- Kibana bootstrap for a Data View and saved queries

## 1. Run

```bash
cd logs_service/fluentd_kibana_template
docker compose up -d --build
```

## 2. Access

- Kibana: `http://localhost:5602`
- Elasticsearch: `http://localhost:9201`

Login credentials:
- username: `elastic`
- password: value from `.env` (`ELASTIC_PASSWORD`)

## 3. What is created automatically

- Data View: `fluentd-template-*`
- Saved Query: `Linux System Logs`
- Saved Query: `API Calls`
- Saved Query: `API Errors (Structured)`

Structured API log fields generated by simulator:
- `Id`
- `Timestamp`
- `Level`
- `Message`
- `Request`
- `Response`
- `Path`
- `Method`
- `StatusCode`
- `RequestSizeKb`
- `ResponseSizeKb`
- `Exception`

In Kibana:
1. Open Discover
2. Select data view `fluentd-template-*`
3. Load saved query `Linux System Logs` or `API Calls`
4. Save to Dashboard

## 4. Stop

```bash
docker compose down
```

## 5. Security notes

- Change all passwords in `.env` before real usage.
- This setup uses HTTP for local dev simplicity.
